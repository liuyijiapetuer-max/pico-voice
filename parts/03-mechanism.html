CHAPTER 03 · 机制

作品机制与「显影」开场

♪
SONOSPHERE

声之建筑

听见的每一秒，在空间里长出会发声的建筑。

一段 60 秒的声音被切成 24 片，绕着你立成 24 根柱子。柱子越高，那一刻的能量越强；每根柱子都是一个真实声源，你绕着建筑走，声音也跟着转。

3.1基本映射

输入 / 元素映射评委能读出什么
60 秒真实音频切成 24 片（每片 2.5 秒）时间有结构了——不是一条连续的流，是可以被「立起来」的 24 个瞬间
一根柱子= 一片（24 根，等角分布成环，半径 1.6 m）「一根柱子 = 一秒」——路演首句就说清
柱高= 该片总能量（0.15 – 1.4 m）响的地方高，静的地方矮 —— 建筑的轮廓就是这段声音的动态
柱色= 频谱重心：低频深琥珀 / 中频橙 / 高频冷白不用看数据也能感到「这段声音是沉的还是脆的」
柱面纹理= 该片 24 频带能量的竖条（128 列 → 24 格，烘焙进贴图）凑近看，每根柱子内部也有结构 —— 细节是「真做出来的」的信号
柱顶标签= 时间码 / 频段 / 响度 dB可读 = 可讨论。评委能指着某根柱问「这段是什么」
地面光环同心光环 = 时间轴，当前播放位置那圈亮起「现在听到的是第几秒」——空间化的进度条

3.2建筑感的三层（缺一层就退化成「声音可视化」）

「把声音画成柱子」本身并不稀奇，任何频谱可视化都能做。让它成为「建筑」的，是下面三层叠起来。

层手段评委感知为什么这一层不可省
几何层Stage 沉浸场景 + 24 柱环形 + 地面声呐光环 + 暗场「我站在一圈柱子中间」只有 Stage 能让声源绕着你走；窗口体放不下这个环
指向层Directivity(pattern, sharpness) 逐柱不同「我绕到这根柱子后面，它变闷了」这是「声音真的在那个位置」最省力也最难反驳的证明——不是音效在循环，是有方向的声源
混响层reverbVolume + AudioMixerGroupResource.setVolume()「整个空间的大小 / 材质在变」同一个声音换个混响 = 换了个房间。这一层直接命中「建筑」的语义
指向层的额外收益 让低频柱用更全向的 pattern、高频柱用更聚焦的，评委就能听出这是两套不同的空间线索：低频包裹感强、高频定位感极强。 这是零成本的设计判断，但听起来立刻「专业」。

3.3开场仪式：把「显影」做成一个参数

官方 Stage 有四种 style，其中 Progressive 可以用 immersion（0–100）连续调节「真实环境透传」与「虚拟场景」的比例：

immersion = 0 → 几乎纯真实房间，虚拟实体不可见 immersion = 50 → 真实环境与虚拟场景各占一半（真实环境的光照仍来自 VST） immersion = 100 → 等价于 Full：纯虚拟场景，真实环境被完全遮住
这就是「显影」本身 immersion 从 0 推到 100：你眼前的客厅像一张照片在显影液里慢慢浮出，变成由声音构成的建筑。

不需要任何模型、贴图或动画资产——只需要一个参数在 6 秒内推过去。这是零资产成本、零外部依赖、且在模拟器上就能验收的戏剧性开场。
manifest 配置项取值说明
pico.spatial.stage.idSONOSPHERE默认 Stage 的唯一名
pico.spatial.stage.style待实测Progressive 对应的数字枚举 —— 文档只给了名字（Automatic / Mixed / Progressive / Full），没给数字。W1 第一天必须四个取值各试一遍
pico.spatial.stage.immersion50默认沉浸度；开场动画从 0 推到 100
pico.spatial.stage.immersion_min0下限
pico.spatial.stage.immersion_max100上限
pico.spatial.stage.upperlimb1上肢可见 —— 交互时手在画面里是加分项
退路（必须提前想好） 若 Progressive 在模拟器上不可用或表现不对，退路是 Mixed + 自做一个内翻的暗色天球盖住 VST，再用贴图与自发光压出暗场。视觉上仍有「暗房 / 显影」的语汇，只是失去「真实房间被吞掉」那一层戏剧性。这条退路不依赖任何新 API。
